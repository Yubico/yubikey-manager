Command-line tool and libraries for configuring and managing YubiKeys over USB
and NFC. Version 6 is a complete rewrite in Rust, with Python bindings available
separately. The native `ykman` CLI does not require Python.

[IMPORTANT]
====
Version 6 is currently in beta. Commands, APIs, and behavior may change before
the stable release. Users upgrading from 5.x should read the
link:doc/Migration_5-6.adoc[migration guide].
====

See link:NEWS[release notes] for changes and
https://github.com/Yubico/yubikey-manager/issues[report beta issues on GitHub].
Include the output of `ykman version`, your operating system, and steps to
reproduce the problem. Remove credentials and other sensitive information
before sharing logs.

If you're looking for a graphical application, check out
https://developers.yubico.com/yubioath-flutter/[Yubico Authenticator].

=== Installation

==== Windows and macOS installers

Download the version 6 beta installer for your platform from the
https://github.com/Yubico/yubikey-manager/releases[Releases page].
Windows installers are available for x64 and ARM64 and bundle a background
service that allows FIDO management without running the CLI as administrator.

See link:doc/Platform_Notes.adoc[platform notes] for macOS Input Monitoring
permissions and uninstallation.

==== Cargo

Install the native Rust CLI, selecting the beta explicitly:

[source,sh]
----
cargo install ykman-cli --version 6.0.0-beta.0 --locked
----

Building requires Rust 1.88 or later and the
link:doc/Development.adoc[platform build prerequisites].
The installed executable is named `ykman`. Ensure Cargo's binary directory
(`$HOME/.cargo/bin` by default, or `%USERPROFILE%\.cargo\bin` on Windows) is on
`PATH`.

==== Python package (migration only)

The `yubikey-manager` Python package distributes the native executable to ease
migration from earlier Python-based versions. Installing the Rust CLI directly
is preferred. This migration package requires Python 3.11 or later:

[source,sh]
----
python -m pip install --pre yubikey-manager
----

This installs only the CLI, not the Python SDK. See <<libraries,Libraries>>
for SDK installation.

==== Linux prerequisites

Smart card and NFC access require the system PC/SC client library
(`libpcsclite.so.1`) and `pcscd` running or socket-activated.

HID access may require your distribution's YubiKey udev rules and suitable
device permissions. See link:doc/Device_Permissions.adoc[device permissions].
Saving credentials requires a session D-Bus and a Secret Service provider,
such as GNOME Keyring.

==== Third-party packages

Packages are available from Homebrew, MacPorts, and Linux distribution package
maintainers. These may still provide the Python-based 5.x release; check the
packaged version before installing. FreeBSD is not officially supported; see
link:doc/Platform_Notes.adoc[platform notes].

=== Upgrading from 5.x

Version 6 has breaking CLI and Python API changes. For example, NFC-connected
YubiKeys are now discovered alongside USB devices; use `--device` to select by
serial number instead of `--reader`.

For Python installations, use a new virtual environment or uninstall the old
`yubikey-manager` distribution before installing either new package. An
in-place upgrade can delete files now owned by the separate `yubikit` package.
The link:doc/Migration_5-6.adoc[migration guide] includes upgrade and repair
commands and details of Python API changes.

If multiple installations provide `ykman`, check which executable your shell
resolves and use `ykman version` to confirm that you are running the beta.

=== Usage

The CLI supports device configuration and the OATH, Yubico OTP, PIV, FIDO,
OpenPGP, YubiHSM Auth, and Security Domain applications.

[source,sh]
----
ykman --help
ykman list
ykman list --serials
ykman --device 123456 info
ykman oath --help
----

Use `ykman <command> --help` for command details. The
https://docs.yubico.com/software/yubikey/tools/ykman/Using_the_ykman_CLI.html[YubiKey Manager CLI User Manual]
provides further usage information and examples; during the beta, installed
command help is the reference for version 6 command syntax.

=== Libraries

To install the Python SDK beta (Python 3.11 or later):

[source,sh]
----
python -m pip install --pre yubikit
----

Neither Python distribution installs the other. See
link:doc/Scripting.adoc[scripting] and link:examples/README.adoc[examples] for
Python usage, and the Rust crate READMEs for beta dependency declarations.
Published API documentation may describe a different release; select the
matching version where available.

=== Versioning and compatibility

Stable releases follow https://semver.org/[Semantic Versioning]. The CLI is
versioned as 6.x, while the Rust libraries and Python SDK have their own 1.x
versions. Specify dependency ranges that exclude untested major versions:
for example `>=1, <2` for the stable Python SDK.

Private Python names (starting with `_`) are not part of the public API.
